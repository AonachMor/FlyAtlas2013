FlyAtlas APIs

 

The FlyAtlas database can be queried through programmatic HTTP requests to the ‘flydirect’ server application, allowing tissue expression data for individual genes to be retrieved in formats suitable for use by program developers. The formats available are plain-text (tab-separated) or XML.

Base URL

http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?

Argument: idtype

This is required, and must have as value one of: ‘fbgn’, ‘cgnum’, ‘symbol’ or ‘name’.

Argument: gene

This is required, and must have a value appropriate to the idtype, and be in the correct case. Spaces must be URL-escaped (see example 5, below). Greek (UTF-8) and Romanized characters are supported.

Argument: output

This can have the values ‘txt’ or ‘xml’. If the argument is omitted, the output format defaults to plain-text.

Example Queries

1. http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?idtype=fbgn&gene=FBgn0016038
2. http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?idtype=cgnum&gene=CG16834
3. http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?idtype=symbol&gene=W
4. http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?idtype=name&gene=hamlet
5. http://motif.mvls.gla.ac.uk:8080/flydirect/index.html?idtype=name&gene=wings+down&output=xml

These can be tested by pasting into the address bar of a web browser. Note that example 4 lists the results of hybridization of mRNA from the same gene to two different probe sets.
